# Pawlix

Storefront and admin for [pawlix.com](https://pawlix.com). Built with Next.js and Supabase.

The build plan is in `pet-commerce-master-build-spec.md`. Work one phase at a time.

## Local setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm test
npm run lint
```
